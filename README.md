# Название проекта
#  Маркетплейс Loooom

Краткое описание: Создания рабочего маркетплейса где могут вкладывать тавары и информацию где есть админ панели, понел продавца, аккаунт пользователя 😅
Команда;
№1 Тұрдыбек Дәлел backend
#2 Сейпіл Данияр Frontend
#3 Сериккали Бекаман Frontend

## 🚀 Стек технологий
* Frontend HTML / CSS / JavaScript
* Basckend; база данный; mySQL/PHP/Python
* 
* другие библиотеки

## 🛠️ Установка и запуск
1. Клонируйте репозиторий:
   git clone https://github.com/diko-cat/web-zal.git
2. Откройте файл
`index.html`


## ⚙️ Основной функционал

* **Аутентификация и профиль**
  * Регистрация и авторизация пользователей
  * Управление личным аккаунтом

* **Управление и администрирование**
  * Панель администратора (Admin Panel)
  * Кабинет продавца / Управление собственным магазином

* **Каталог и взаимодействие**
  * Выбор и сортировка товаров (включая выбор категории/сорта)
  * Добавление в «Избранное» (Понравилось)
  * Встроенный мессенджер для общения с друзьями или продавцами

* **Покупка и отслеживание**
  * Оформление покупки
  * Статус ожидания и отслеживание состояния товара в реальном времени
